# Lithuanian alpinism terminology

`docs/terminology-lt.md` is the reference for every climbing, mountaineering and ski-touring term in
Lithuanian text. Climbers' Lithuanian is not a translation of English: "ice axe" is *ledkirtis*, not
"ledo kirvis", a pitch is a *virvė*, a harness is *apraišai*. Word-by-word translation produces text
no Lithuanian climber would write.

## Before you write

1. Read `docs/terminology-lt.md` in full (it is grouped by type: activities, landforms, rock, glaciers,
   snow and weather, hazards, ropes and knots, belaying, hardware, clothing and camping, skis and lifts,
   expeditions, medicine, routes and grades, huts, verbs, and a "Do not write" list).
2. Note the terms the text needs. For each, use the **Write** column; the first form is the default.
3. Check the "Do not write" table against your draft.

## Rules

- Use the **Write** form. Forms marked *žod.* are the 2020 dictionary's preference and are not the
  default; *šnek.* (slang) only in a quote or a deliberately informal diary line; never *ntk.*
- An entry marked **?** is unsettled. Use it if you must, and say which **?** terms the text relies on
  so they can be settled.
- A term that is not in the file: do not invent or translate one. Ask, then add the term to the file
  in its group, with its source and a **?** mark if it is not confirmed.
- A compass side that describes a face, ridge, couloir or slope is an adjective, not a genitive:
  "šiaurinė siena", "rytinė ketera", "pietvakarinis kuluaras", "pietrytinis šlaitas" (not "šiaurės siena",
  "rytų ketera"). A direction of travel stays a noun: "į rytus", "į šiaurės rytus".
- Captions and any new text must use the same word as the report's existing text for the same thing
  ("uolų laiptas", "ledo laiptas", "luitas", "atšaka", "stotis"): read the trip's text before you write a caption.
- Names are never translated (Col du Midi, Adlerpass, Glacier du Géant), even where the common noun has
  an entry.
- When a term is corrected, update `docs/terminology-lt.md` in the same change, so the correction holds
  for every later text. If the change affects words in existing texts, say which.
